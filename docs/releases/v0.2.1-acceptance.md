# siderostat v0.2.1 acceptance

## Status

Status: **RELEASE BLOCKED / CANDIDATE ARTIFACT BUILT**

`54fd88f`を実装基準として、v0.2.0 acceptanceのautomated gate、2-node installation、deployment
mismatch、H-03 process restartの再検証を行った。Required CI、production reconnect 37件、release build、
artifact監査、digest cache緩和、通常の2-node DistributedReady、deployment mismatch restart抑止はPASSした。

H-03 coordinator-only restartの1回目で、workerのowned distributed childがSIGTERMで終了せず、
install生成configの`allow_sigkill=false`により180秒後の安全なSIGKILLも拒否された。workerは
`SoloStandaloneStarting + Unavailable`に残り、coordinatorはSolo servingを維持したものの、
peer loss／pairingとpromotion failureを反復した。このため残りのprocess restart、物理cable、macOS
restart、upgrade/rollback試験を停止し、releaseをBLOCKEDとする。

### Failure timeline

- 12:37:05Z: coordinator runtimeをrestart。
- 12:37:07Z: workerがDistributedReadyからpeer-loss recoveryへ入り、owned worker child停止を開始。
- 12:40:07Z: 180秒後、`SIGKILL is not allowed for this child`でrecovery失敗。
- workerは`SoloStandaloneStarting`、admission blocked、HTTP readiness 503。coordinatorはSolo serving。
- installed worker configをbackup後`allow_sigkill=true`へ変更し、worker runtimeをrestart。
- stale child cleanup後に再pairing・promotionし、worker generation 242、coordinator generation 634で
  両node DistributedReady／servingへ復旧。
- 復旧後のPairingと「ノード検出」通知は1回だけであり、通知ループは停止失敗から派生した状態反復と判定。
  通知ロジック固有の修正は行わない。

Recovery用backupは
`~/Library/Application Support/siderostat/config.toml.acceptance-backup-20260818-2141`に保存した。
