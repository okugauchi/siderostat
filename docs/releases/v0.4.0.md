# Siderostat v0.4.0

## Changes

- Add gated two-node tensor parallelism using the upstream DS4 RDMA/TP contract.
- Persist Automatic / ForcedStandalone operation policy, reject unsuccessful policy transitions, and coordinate child supervision and menu state.
- Provide an optional, opt-in SearXNG Web Search Bridge for the Responses API.
- Preserve the accepted H05 runtime and monitor behavior. The DS4 source/model/activation manager (H06) is deferred to v0.5.0 or later.

## Compatibility and acceptance

- Exactly two Apple silicon Macs connected through Thunderbolt networking; verified model: DeepSeek V4 Flash.
- Verified DS4 source: `0aaea5a238fb41a35106a551e73c8409dfb751ac`. Compatibility must be checked before changing the upstream source, binary, or model.
- Saved H07 acceptance at commit `61e66e4b2a1dcefe2b3284df6ed911b427c8b0eb`: workspace fmt/clippy PASS; 66 test suites, 1037 passed, 0 failed, 0 ignored. One independent reviewer completed review and re-review with no outstanding findings.
- Build 5 was accepted on both Macs on 2026-10-11: health/readiness/cluster HTTP 200, Automatic/distributed-ready, and Chat HTTP 200. A 3535.22-second response under parallel workload was accepted by the operator as incidental contention; this is not a latency guarantee.
- On 2026-10-11 the operator explicitly chose saved PASS evidence instead of rerunning tests after integration. Release preparation changes documentation only; implementation identity is checked against the accepted source. No new test run is claimed.

## macOS artifacts

Build 6 is generated from the release tag. Install the same `Siderostat-0.4.0-no-timestamp.pkg` on both Macs with macOS Installer. The DMG contains the package, Uninstaller, and README.

Artifacts are Developer ID signed, with `timestamp_mode=none`, `notarization=skipped`, and `distribution_ready=false`, following the 0.x policy. They are not notarized distribution-ready artifacts. Configuration, credentials, models, caches, and runtime state are not included.

## Recovery

The uninstaller preserves user data. The v0.3.4 installer remains available for manual recovery; restoration of an old data snapshot is not guaranteed. Plan downtime and verify compatibility before rollback.
