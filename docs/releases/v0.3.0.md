# siderostat v0.3.0

Status: released (source)

## Highlights

- メニューバーモニターに、現在の動作状態、推論の進行状況、progress age を表示する。
- `siderostat-runtime` の起動、停止、自動起動、graceful restart をメニューから操作できる。
- 計画再起動時に2ノードを協調させ、重複 child や再接続 loop を残さず分散稼働へ復帰する。
- 同じ recovery epoch 内の Standalone、Paired、Distributed 通知を重複抑制する。
- throughput degradation の診断、bounded canary、手動復旧、および opt-in の自動復旧を追加する。
- 設定、認証情報、モデル、KV cache を保持したまま更新・rollback・uninstall できる。

## Installation and update

両方の Mac で同じリビジョンを checkout し、次を実行する。

```sh
cargo xtask fingerprint-models
cargo xtask install --start
```

更新時も同じコマンドを使う。両方の Mac が `Solo Standalone` で準備完了になってから
Thunderbolt ケーブルを接続する。詳細は[導入ガイド](../installation.ja.md)を参照する。

## Rollback and uninstall

Rollback では以前に確認したリビジョンを checkout し、通常の導入コマンドを再実行する。
異なるリビジョンからビルドした runtime を2ノード間で混在させないこと。

アンインストールには次を使用する。

```sh
cargo xtask uninstall
```

設定、認証情報、モデル、runtime state、cache は保持される。

## Recovery behavior

自動的な縮退復旧は既定で無効である。管理者が有効にした場合も、試行回数と cooldown に
上限がある。復旧に失敗した場合は要求受付を閉じ、手動対応を求める。失敗した利用者要求を
Siderostat が自動再送することはない。

## Known limitations

- Apple シリコン Mac 2台の構成だけに対応する。
- 現在の確認済みモデルは DeepSeek V4 Flash である。
- 状態切り替え中や推論サービス起動中には、短時間の HTTP 503 / 504 が発生し得る。
- Mac 間の tensor parallelism、RDMA transport、distributed DSpark には対応しない。
- automatic degraded recovery は opt-in である。
