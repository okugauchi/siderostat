# siderostat v0.3.4 acceptance

Status: release candidate

## Release identity

- Version: `0.3.4`
- Build number: `31`
- Release branch: `hotfix/0.3.4/macos-27-app-pkg`
- Release tag: annotated `v0.3.4`
- Official distribution: signed and notarized `.pkg` and DMG
- Installation route: macOS Installer opening `Siderostat-0.3.4.pkg`

## Automated verification

The release gate requires the following checks to pass on the tagged source revision:

```sh
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets
cargo check --workspace --locked
git diff --check
```

The package gate requires an inside-out Developer ID signature, a signed flat package whose payload
contains only `/Applications/Siderostat.app`, successful notarization, stapling, and Gatekeeper
verification of the app, package, and DMG.

## Regression acceptance

The macOS 27.0 regression is accepted when a cold boot of each node starts exactly one
`Siderostat.app` Monitor, does not open a terminal for runtime errors, and leaves the bundle-contained
runtime as the only Siderostat service. The two-node pair must reach:

- both nodes `distributed-ready`
- both nodes `admission=serving`
- both nodes `in_flight=0`
- `/healthz` and `/readyz` returning HTTP 200
