## Remaining finalization gates

1. 仮 commit を精査・圧縮し、reviewable な final candidate commit を固定する。
2. final candidate commit から source archive、file list、SHA-256 を再生成する。
3. final revision で automated verification と tracked-source 混入検査を再確認する。
4. 8項目をすべて PASS に更新した後、ユーザーが最終 release 可否を承認する。
