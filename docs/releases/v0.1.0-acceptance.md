## Required cable-cycle procedure

1. 両nodeをPaired Standalone readyにする。
2. Cableを抜き、両nodeがpolling待ちではなくnetwork event後にSolo Standalone readyへ収束することを確認する。
3. Cableを戻し、固定address/route、HMAC lease、Paired Standalone readyへの復帰を確認する。
4. 10回繰り返し、各cycleでproxy 1、DS4 child最大1、orphan transition/PID/port残留なしを記録する。
5. Thunderbolt dockだけのeventをpeer presentとして扱わないことを確認する。

完了後、このrecordとsecurity/endurance recordをPASSへ更新し、P7-03を閉じる。
