# siderostat v0.3.1 acceptance

Status: PASS / RELEASE PUBLISHED

## Scope

v0.3.1 は、ds4 main の現行 CLI と Siderostat DSpark 起動引数を整合させる patch release である。
モデル、secret、runtime state、cache、`scripts/update-ds4-main-and-restart.zsh` は release 対象外とした。

## Automated verification

以下を release candidate で実行する。

```sh
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets
cargo check --workspace --locked
git diff --check
```

DSpark 回帰テストは `--mtp-model` が1回だけ出力され、旧 `--mtp` が出力されないことを確認する。
依存関係は v0.3.0 から変更せず、inventory は
[`v0.3.0-dependencies.md`](v0.3.0-dependencies.md) と `Cargo.lock` を照合する。
