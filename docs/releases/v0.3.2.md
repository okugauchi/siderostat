# siderostat v0.3.2

Status: release candidate

## Fixes

- macOS の `SCDynamicStore` 通知登録を、絶対 Dynamic Store path の POSIX regex と空の
  `keys` 配列で行うように修正した。
- `bridge0` 配下の link / IPv4 と Network Service 設定の変更を、macOS 27.0 の起動時・
  再接続時にも再スキャンできるようにした。初期スキャンが bridge0 の IPv4 設定反映前に
  実行されても、Solo Standalone からの自動ペアリングが停止し続けない。

## Release scope

- v0.3.2 は v0.3.1 を基準にした source-only patch release である。
- モデル、secret、runtime state、cache、ユーザーデータは release source に含めない。
- macOS の事前ビルド済み `.app`、`.pkg`、DMG はこの変更では作成・配布しない。

## Installation and update

Siderostat の source checkout で次を実行する。

```sh
cargo xtask install --start
```

2台構成では MacBook Pro と Mac Studio の両方を同じ v0.3.2 source revision へ更新し、
`cluster doctor` が readiness に到達してから Distributed への自動遷移を確認する。

## Known limitations

- Apple silicon Mac 2台の構成だけに対応する。
- Mac 間の tensor parallelism、RDMA transport、distributed DSpark には対応しない。
- automatic degraded recovery は opt-in である。
