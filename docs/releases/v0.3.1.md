# siderostat v0.3.1

Status: released (source)

## Fixes

- DSpark の support model を、現行 ds4-server が受け付ける `--mtp-model FILE` で渡すように修正した。
  これにより、ds4 の main 更新後に Siderostat runtime が起動直後に終了する問題を防ぐ。
- `extra_args` から生成済みの `--mtp-model` を重複指定できないようにした。
- ds4 更新スクリプトに、DSpark 起動引数の互換性検査を追加した。

## Release scope

- v0.3.1 は v0.3.0 と同じ source-only release 方針である。
- モデル、secret、runtime state、cache、ユーザーデータは release source に含めない。
- `scripts/update-ds4-main-and-restart.zsh` はプロジェクトの release 対象外であり、commit、tag、source archive に含めない。
- 依存パッケージの追加・更新はない。依存関係の inventory は
  [`v0.3.0-dependencies.md`](v0.3.0-dependencies.md) を継続して参照する。

## Installation and update

Siderostat の source checkout で次を実行する。

```sh
cargo xtask install --start
```

モデルを変更していない更新では、model fingerprint の再計算は不要である。2台構成では両方を
同じ v0.3.1 source revision へ更新し、両方が readiness に到達してから分散稼働を確認する。

## Known limitations

- Apple silicon Mac 2台の構成だけに対応する。
- 現在の確認済みモデルは DeepSeek V4 Flash である。
- Mac 間の tensor parallelism、RDMA transport、distributed DSpark には対応しない。
- automatic degraded recovery は opt-in である。
