# siderostat v0.3.4

Status: released

## Fixes

- macOS の bundle 外で起動する legacy source workflow が、`SMAppService` の Login Item を
  登録しないようにした。`launchd` とログイン時自動起動による Monitor の二重起動を防ぐ。
- 正式な導入経路を `Siderostat.app` を payload とする署名済み `.pkg` に固定した。

## Release scope

- v0.3.4 は v0.3.3 の macOS 27.0 hotfix を正式配布向けに整理した patch release である。
- Developer ID Application / Installer で署名し、Apple secure timestamp、公証、staple を付けた
  `.pkg` と DMG を作成する。
- モデル、secret、runtime state、cache、ユーザーデータは release artifact に含めない。

## Installation and update

両方の Mac で、同一の `Siderostat-0.3.4.pkg` を macOS Installer から導入する。
`cargo xtask install` は使用しない。旧 source 導入が残っている場合だけ、更新前に
`cargo xtask uninstall` を実行する。

## Compatibility

- Apple silicon Mac 2台を Thunderbolt networking で接続する構成を対象とする。
- macOS の対応最低バージョン、モデル、DS4 binary の互換性条件は既存の v0.3.x 方針を引き継ぐ。
- Mac 間の tensor parallelism、RDMA transport、distributed DSpark は対象外である。
