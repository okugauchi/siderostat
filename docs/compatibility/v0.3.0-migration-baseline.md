## 5. runtime / monitor / DS4 child の所有関係・port・command

| 項目 | 値 |
|---|---|
| runtime の DS4 child 所有 | runtime が manifest-approved `ds4-server` executable を child として所有・検証・停止（mode-aware cluster supervisor） |
| runtime public port | `127.0.0.1:18080`（`proxy.public_listen`） |
| runtime admin port | `127.0.0.1:18081`（`proxy.admin_listen`、/healthz /readyz /cluster /metrics） |
| DS4 HTTP | `127.0.0.1:8000`（`ds4.http_port`） |
| cluster control port | 9920 / ds4 distributed 9911 / peer ingress 18082 |
| install command | `cargo xtask install` |
| verify command | `cargo xtask verify` |
| uninstall command | `cargo xtask uninstall`（bootout + plist rename .disabled。model/KV cache/secret/state は保持） |
| monitor LaunchAgent control | `monitor/src/launchd.rs` の `kickstart` / `bootout_runtime_and_monitor`（legacy `launchctl` 直接呼出し。新 bundle では Service Management + admin API に置換） |
| default config path 解決 | `resolve_config_path`（`src/config.rs`）: `--config` → `SIDEROSTAT_CONFIG` → cwd `siderostat.toml` → macOS `~/Library/Application Support/siderostat/config.toml` |

## 7. local gate 結果（2026-08-19）

A-02 は文書 task のため `git diff --check` と記載 path の存在確認を共通 gate として実行。Rust code を変更しないため `cargo fmt/clippy/test` のフル再実行は不要だが、baseline として `cargo fmt --check` と `cargo clippy --all-targets --all-features -- -D warnings` を実行した（結果は本セクション末尾に追記）。secret 本文、完全な deployment ID、API token は本文書に含めない。
