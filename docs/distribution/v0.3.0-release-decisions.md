## 2. runtime graceful restart endpoint contract

launchd が runtime を新 binary で再起動できる graceful path を提供する admin endpoint。C-04 で実装。

- **method**: `POST`
- **path**: `/admin/restart`
- **認証**: `Authorization: Bearer <admin token>`（既存 admin API と同じ `cluster.security.admin_token_file` から読み出す bearer token）
- **request body**（省略可）:
  ```json
  { "drain_timeout_ms": 30000 }
  ```
  未指定時の default drain timeout は config の cluster stop timeout を使用。
- **成功**: `202 Accepted`
  ```json
  { "restart": "accepted", "drain_timeout_ms": 30000 }
  ```
  処理は admission block → in-flight drain → owned DS4 child stop → runtime process exit の順で行い、exit 前に `202` を返してクライアントへ曖昧な transport error を見せない。
- **認証失敗**: `401 Unauthorized`
  ```json
  { "error": "unauthorized" }
  ```
- **drain timeout / child identity mismatch**: `409 Conflict`（強制 kill せず error を返す）
  ```json
  { "error": "drain_timeout", "in_flight": 3, "drain_timeout_ms": 30000 }
  { "error": "child_identity_mismatch" }
  ```
- **重複要求 / 進行中の restart**: `409 Conflict`
  ```json
  { "error": "restart_in_progress" }
  ```
- 停止条件（迂回禁止）: cluster lifecycle owner を迂回した signal、unknown PID の kill、unauthenticated endpoint は使わない。

## 3. first launch / migration の UX 文言（日本語、承認待ち → 承認済み 2026-08-19）

- first launch の背景説明: 「Siderostat のバックグラウンド実行を登録します。登録後、このアプリを終了しても推論サービスは動作し続けます。」
- 登録成功: 「バックグラウンド実行を登録しました。システム設定のログイン項目に Siderostat が表示されます。」
- `requiresApproval` / 拒否時: 「バックグラウンド実行の承認が必要です。システム設定 > 一般 > ログイン項目を開いて、Siderostat を許可してください。」（「ログイン項目を開く」ボタンを表示）
- 登録失敗: 「バックグラウンド実行の登録に失敗しました。もう一度お試しください。」
- monitor login start 説明: 「ログイン時に Siderostat メニューバーを表示します。」
- migration 説明: 「以前のインストールを検出しました。重複起動を避けるため、旧バージョンのサービスを停止して新しいサービスへ移行します。設定・モデル・データは保持されます。」
- migration 成功: 「移行が完了しました。旧バージョンは削除可能です。」
- migration 失敗 + rollback: 「移行に失敗したため、以前のバージョンを復元しました。設定は変更されていません。」
- Runtime を再起動: 「推論サービスを再起動します。進行中の処理を終了させた後、新しい状態で起動します。」
- バックグラウンド実行を停止: 「バックグラウンド実行を停止します。推論サービスが終了し、次回起動時に自動で開始されません。」

## 4. 関連する決定の根拠メモ

- 非目標（配布仕様 3.2 節）をそのまま維持: Mac App Store、App Sandbox、privileged LaunchDaemon、`SMJobBless`、Intel universal binary、GGUF/DwarfStar 同梱、自動 update framework、`.pkg` 単体 uninstall は対象外。
- `Siderostat.app` の main executable は `siderostat-monitor`、`Contents/Helpers/siderostat-runtime` は `siderostat` binary（crate 名の即時 rename は不要、配布仕様 5.1）。
- bundle 内 LaunchAgent plist は install/first launch 時に書き換えず、`BundleProgram` 相対 path を使う（配布仕様 5.4）。
- signing は inside-out、`--deep` 不使用、配布で `get-task-allow` を含めない（配布仕様 8.2、8.3）。
- `.pkg` は scriptless flat installer、payload は `/Applications/Siderostat.app` 一項目（配布仕様 9）。
